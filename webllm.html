WebLLM 本地对话 Demo

与 Transformers.js 版并列的第二种浏览器推理实现：WebLLM（MLC）把模型编译为 WebGPU 可执行的 MLC 格式， 推理全程在 GPU 本地完成。可与另一版对比「引擎、模型格式、后端、下载体积、生成速度」的差异。

⚠️ WebLLM 的模型与运行库来自 HuggingFace / GitHub raw，国内网络通常需要代理才能下载。

两种浏览器推理方案对比（实现记录）

维度Transformers.js 版（本机已跑通）WebLLM 版（本页）
引擎Transformers.js v3 + ONNX Runtime WebWebLLM（MLC LLM）
模型格式ONNX（fp16 / q8 / q4）MLC 编译格式（q4f16 等）
后端WebGPU 优先，WASM 回退仅 WebGPU
任务范围分类 / 向量 / 生成，可多任务共存以对话生成为主，推理性能更强
首次下载20MB–450MB（按任务）350MB–1GB（按模型）
国内网络支持 hf-mirror 镜像依赖 HF / GitHub raw，通常需代理
